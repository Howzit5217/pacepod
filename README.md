# PacePod

A little speedometer that floats over Pikmin Bloom while you ride, and tells you when to slow down or speed up.

**Get it:** https://howzit5217.github.io/pacepod/

- **Android:** download the APK from the page (or [Releases](https://github.com/Howzit5217/pacepod/releases/latest)).
  After that it updates itself: every few hours it checks this repository's latest release and installs a newer
  one while the pill is out of the way (long-press the pill and tap Allow next to Updates, once).
- **iPhone:** the web version at https://howzit5217.github.io/pacepod/app/. Open it in Safari and Add to Home
  Screen. iPhones don't let apps float over other apps, so there it's a full-screen speedometer.

This repository holds the website (`index.html`) and the web version (`app/`), which reloads into a new version by
itself. Your location never leaves your phone: the only thing the app fetches is its own updates.

PacePod is a fan-made tool, not made by or affiliated with Niantic or Nintendo.
